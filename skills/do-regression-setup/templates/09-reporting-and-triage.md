## Triage loop — every red run ends in one of three places

| Verdict | Meaning | Route |
|---------|---------|-------|
| **App bug** | the app violates decided behavior (AC / contract / integrity rule) | log it against the feature → **`do-fixing`** (or **`do-issue-grooming`** if the failure suggests a project-wide class); link the failing regression test as the repro |
| **Test defect** | the test is wrong/brittle (bad wait, stale data assumption) | fix here, per `08-stability-policy`; if the locator broke because an app Test ID changed, that's an **app contract violation** (IDs are never renamed) — raise it |
| **Intended change** | the app changed behavior deliberately (a shipped feature altered a flow) | update the test **against the feature's updated TRD/AC** — never loosen an assertion just to go green; if no TRD records the change, that's an Open Decision for the app side |
