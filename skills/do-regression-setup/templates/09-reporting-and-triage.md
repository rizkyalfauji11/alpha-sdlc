## Triage loop — every red run ends in one of three places

| Verdict | Meaning | Route |
|---------|---------|-------|
| **App bug** | the app violates known behavior (PRD rule / learned model / contract) | **report to the app team** — their tracker (or their `do-fixing`/`do-issue-grooming` if they use this plugin), with the failing regression test's steps + artifacts as the repro |
| **Test defect** | the test is wrong/brittle (bad wait, stale data assumption) | fix here, per `08-stability-policy`; if a locator broke because a stable test ID was renamed in the app, **raise it with the app team** — renamed IDs break every QA suite |
| **Intended change** | the app changed behavior deliberately (a new build altered a flow) | update the test **against the confirmed new behavior** (updated PRD / user confirmation, recorded in `04`'s learned model) — never loosen an assertion just to go green; an unannounced behavior change is itself a finding to report |
